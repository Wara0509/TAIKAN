# 服装戦略提案アプリ (TAIKAN)

このプロダクトは「天気表示アプリ」ではなく、
**朝の服装意思決定を代替するための戦略提案アプリ**です。

## STEP1: プロジェクト構成（提案）

この段階では、要件に沿って実装しやすい構成を定義します。

```text
TAIKAN/
├─ README.md                 # プロジェクト概要と開発ステップ
├─ Makefile                  # ビルド/実行コマンド
├─ docs/
│  └─ architecture.md        # 設計メモ（モード構成、データフロー）
├─ include/
│  ├─ model.h                # 構造体定義（入力/分布/戦略/出力）
│  ├─ logic.h                # 計算系関数の宣言
│  └─ ui_cli.h               # CLI入出力関数の宣言
└─ src/
   ├─ main.c                 # エントリポイント（モード分岐）
   ├─ logic.c                # 体感温度・分布・戦略判定
   └─ ui_cli.c               # 即決モード/精密モードのCLI実装
```

## 設計方針

- **戦略中心**: 出力の中心は「半袖/長袖」ではなく「調整前提」「防風対策」などの行動戦略。
- **分布中心**: 単一点の体感温度ではなく、橋・屋外・室内などの分布を計算。
- **拡張前提**: CLIでロジックを完成させ、同じロジック層をGUIから再利用する。

## 予定する主要関数

- `calculate_feels_like()`
- `calculate_distribution()`
- `analyze_strategy()`
- `generate_output()`
