# TAIKAN - 服装戦略提案アプリ

ユーザーが朝「何を着るか」を考えなくても済むようにする、
**戦略出力型のWebアプリ**です。

> 重要: このプロダクトは天気を表示するのが目的ではなく、服装意思決定を代替するのが目的。

## 使い方（Web）

```bash
python3 -m http.server 8080 -d web
# ブラウザで http://localhost:8080
```

## 実装内容

- 即決モード
  - 地域/日付/天気/気温/体感温度/体感差
  - 戦略を大きく表示
- 精密モード（3ステップ）
  - STEP1: 環境
  - STEP2: 移動
  - STEP3: 時間変化
- 結果画面
  - 戦略（組み合わせ）
  - 体感温度の分布
  - 状態（min/max/diff）
  - 行動指針・NG例・服装イメージ

## ロジック仕様

`体感温度 = 基本気温 - 風補正 - 場所補正 ± 日差し補正 ± 活動補正`

- 風: 3/5/8m/s で -1/-2/-4
- 場所: 橋 -1.5, 高所 -1.0, 吹き抜け -1.0, 日陰 -0.5, 日向 +1.0
- 活動: 徒歩多/自転車 +1.5, 普通 +0.5
- 室内: +3.0
- 戦略判定:
  - `diff < 3`: 安定
  - `diff >= 6`: 調整前提
  - サブ: 防風対策 / 寒さリスク / 暑さリスク / 軽装推奨
