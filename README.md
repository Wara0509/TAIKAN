# 服装戦略提案アプリ (TAIKAN)

このプロダクトは「天気表示アプリ」ではなく、
**朝の服装意思決定を代替するための戦略提案アプリ**です。

## 使える実装

### 1) CLI版（通常）

```bash
make
./taikan
```

### 2) 画面操作版 TUI（リンク先で使いやすいUI向け）

```bash
make tui
./taikan_tui
# または ./taikan --tui
```

- 矢印キー + Enter で選択
- 即決モード / 精密モード（3ステップ）を実際に操作可能
- 結果画面で戦略・分布・行動指針・NG例まで表示

## 実装済み要件

- 即決モード（ホーム相当）
  - 地域名 / 日付 / 天気 / 気温 / 体感温度 / 体感差
  - 大きな戦略表示 + 補足コメント
- 精密モード（3ステップ）
  - STEP1: 環境
  - STEP2: 移動
  - STEP3: 時間変化
- 結果画面
  - 戦略（組み合わせ）
  - 体感温度分布（橋・外・室内）
  - 状態（min/max/diff）
  - 行動指針
  - NG例
  - 服装イメージ

## ロジック

体感温度:

`体感温度 = 基本気温 - 風補正 - 場所補正 ± 日差し補正 ± 活動補正`

補正・判定:

- 風補正: 3/5/8m/s で -1/-2/-4
- 場所補正: 橋/高所/吹き抜け/日陰/日向
- 活動補正: 徒歩多・自転車・通常
- 室内補正: +3.0
- diff < 3: 安定
- diff >= 6: 調整前提
- サブ: 防風対策 / 寒さリスク / 暑さリスク / 軽装推奨
