# 服装戦略提案アプリ (TAIKAN)

このプロダクトは「天気表示アプリ」ではなく、
**朝の服装意思決定を代替するための戦略提案アプリ**です。

## ビルド方法

```bash
make
```

## 実行方法

```bash
./taikan
```

## 主要機能（CLI）

- 即決モード
  - 地域・日付・天気・気温・風速を入力
  - 数秒で「戦略」を表示
- 精密モード
  - 3ステップ（環境/移動/時間変化）を選択
  - 体感温度の分布と行動指針を表示

## ロジック

体感温度:

`体感温度 = 基本気温 - 風補正 - 場所補正 ± 日差し補正 ± 活動補正`

戦略判定:

- diff < 3 → 安定
- diff >= 6 → 調整前提
- 風強い → 防風対策
- min < 13 → 寒さリスク
- max > 24 → 暑さリスク
- 活動多 → 軽装推奨
